> 📅 内容基准：2026-11 ｜ ⏱️ 时效性：高 ｜ 🔁 下次复核：2027-02

> 各平台技能生态的精选与最佳实践。2026 年的主线是：**GPT Store 退场、Claude Skills/Plugins 崛起、Cursor 走向 Rules + Skills 双轨**。

---

## 模块概述

本模块汇总各平台的"技能"生态：

- ChatGPT：GPT Store（历史）→ **Plugins / Skills**
- Claude：Projects（背景）→ **Skills（流程）→ Plugins（分发）**
- Cursor：Rules + Skills + AGENTS.md
- OpenCLI：把网站/浏览器变成 Agent 可调用的 CLI

帮助团队快速找到并复用高质量能力，同时看清每个方案的时效性。

**适合人群**：所有人
