# M12 · AI 发展脉络与版本迭代

> 这个模块不是介绍某一个工具，而是帮助团队建立统一视角：AI 是怎么一步步发展到今天的？每次模型、工具、Agent 工作流升级时，我们应该看什么、怎么判断、怎么落地？
>
> 最后更新：2026年6月

---

## 为什么新增 M12？

前面的模块分别讲：

- M1/M4：原理
- M2/M3：模型和工具
- M5/M6：实战和项目配置
- M10/M11：Cloud Agent 与开发提效工具

但团队真正学习时，还需要一条“主线”：

```text
模型能力提升
  → 工具调用出现
  → Agent 能自主执行
  → 多 Agent 协作
  → 目标 Loop / 自审查 / 自迭代
  → 异步 Cloud Agent 和自动化交付
```

M12 就是这条主线。

## 团队使用方式

每次出现新模型、新工具或新工作流时，按这个顺序学习：

1. 先看它属于哪个发展阶段
2. 再判断它解决了什么旧问题
3. 再看是否影响团队现有流程
4. 最后用统一模板做试用结论

这样团队不会被“新名词”带着跑，而是知道它在整个 AI 演进地图里的位置。
