# M12-01 · AI 发展阶段总览

> 讲 AI 不能只讲“某个模型很强”，更要讲清楚它为什么出现在这个阶段、解决了什么问题，以及下一步会往哪里走。
>
> 最后更新：2026年6月

---

## 一张主线图

```text
阶段 1：聊天机器人
  代表：ChatGPT / Claude / Gemini
  核心：会回答问题

阶段 2：工具调用
  代表：Function Calling / Tools / MCP
  核心：能调用外部工具

阶段 3：编程助手
  代表：Cursor / Copilot / Claude Code
  核心：能理解代码并协助修改

阶段 4：Agent 执行循环
  代表：ReAct / Plan-and-Act
  核心：能规划、执行、观察、继续行动

阶段 5：自审查与自迭代
  代表：Goal Loop / Critic / Reflexion / Eval-driven Agent
  核心：能围绕目标自查、修正、验证

阶段 6：异步 Cloud Agent
  代表：Cloud Agent / Devin 类工作流
  核心：能在云端持续运行并交付 PR

阶段 7：团队级 Agent 工作流
  代表：Superpowers / gstack / Agent Teams
  核心：多个角色协作，接近一个虚拟工程团队
```

---

## 每个阶段解决的问题

| 阶段 | 解决的问题 | 新产生的问题 |
|------|------------|--------------|
| 聊天机器人 | 人可以自然语言问答 | 不能直接执行任务 |
| 工具调用 | 能查资料、调 API、跑代码 | 工具太多，调用不稳定 |
| 编程助手 | 能写代码、解释代码 | 容易不验证就交付 |
| Agent 循环 | 能多步骤完成任务 | 会跑偏、循环、成本失控 |
| 自审查自迭代 | 能自查并修正 | 需要明确验收标准 |
| Cloud Agent | 能异步完成长任务 | 需要权限、隔离和 Review |
| 团队级 Agent | 能分角色协作 | 编排复杂度上升 |

## 团队讲解建议

给团队讲 AI 发展时，不建议按厂商讲：

```text
OpenAI 发生了什么 → Anthropic 发生了什么 → Google 发生了什么
```

更建议按能力讲：

```text
回答问题 → 调工具 → 写代码 → 执行任务 → 自审查 → 云端交付 → 多角色协作
```

这样非技术同学也能理解：每一次新版本不是“更聪明一点”，而是在解决上一阶段暴露出来的新瓶颈。

---

## 当前最重要的变化

截至本课程当前版本，最值得团队重点理解的是：

1. **模型能力正在商品化**  
   单纯比较“谁更聪明”越来越不够。

2. **上下文工程变得重要**  
   谁能把正确资料、工具、规则、历史状态组织好，谁就更高效。

3. **Agent 工作流成为核心竞争力**  
   真正的差距在：目标是否清楚、是否能自审查、是否能验证结果。

4. **工具接口正在为 Agent 重做**  
   CLI、MCP、Skills、Cloud Agent 都是在让 AI 更容易使用软件。
