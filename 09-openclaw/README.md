## 模块概述

本模块介绍 OpenClaw 的定位、安装配置、Skills 与 MCP 接入。目标是让团队理解：**一个自托管的 Agent 网关能做什么、边界在哪、值不值得长期维护**。

**适合人群**：所有人（安装部分面向有基本命令行经验的同学）

## 30 秒判断：现在还值得学 OpenClaw 吗？

| 你的情况 | 建议 |
|----------|------|
| 想通过 IM 随时用 AI、要持久记忆和定时任务 | ✅ 值得，OpenClaw 仍是这类需求最成熟的开源自托管方案 |
| 团队已有 Claude Cowork / Duet / Copilot 等托管 Agent | ⚠️ 先对比：托管方案省运维，但渠道与数据可控性弱 |
| 没有可长期在线的机器 | ❌ 不适合（网关要常驻） |
| 要求"零运维、开箱即用" | ❌ 不适合（自托管意味着你要为升级、安全、备份负责） |

## 一句话记住它的架构

```
IM 渠道（Telegram / Discord / 微信 / 飞书 …）
        ↓
OpenClaw Gateway（常驻进程，管会话 / 记忆 / 权限 / 工具）
        ↓
Agent 运行时（模型 + Skills + MCP + 自动化 + 配对设备）
        ↓
Control UI（浏览器/桌面/手机）+ 原生 App + 云端会话
```
