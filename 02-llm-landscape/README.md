## 模块概述

本模块横向对比国际与国内主流大模型，包括**当前版本快照（2026-11）**、能力边界、价格口径、适用场景和接入方式，帮助团队在选型时做出理性决策。

本模块采用"**当前快照 + 历史沿革**"结构：

- 每篇都有当前版本时间线、价格快照（带来源和日期）；
- 文末「历史沿革」保留 2024–2026 的关键版本（含已停用版本），记录模型是怎么走到今天的；
- 原理、方法与查询入口长期有效，具体版本和价格每季度复核。

**适合人群**：所有人

## 怎么读（建议顺序）

1. 先看 [M2-03 决策树](./03-comparison.md#二选型决策树2026-11)，用 5 分钟锁定 2–3 个候选；
2. 再到 M2-01 / M2-02 查对应家族的当前版本与价格；
3. 最后用自建评测（20–50 条真实任务）做决定，不要照抄榜单。

> ⚠️ 模型版本与价格变化很快。本模块的数字都标注了"读取日期"，**超过 3 个月请重新核对官方定价页**。
