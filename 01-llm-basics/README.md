## 模块概述

本模块介绍大语言模型（LLM）的基本概念、Transformer 架构、训练流程（预训练、微调、对齐、强化学习）以及常用术语速查，为零基础或希望系统梳理的同学打下基础。

2026 年的 LLM 已经不只是"聊天补全"：它默认会**推理（Thinking）**、按**稀疏专家（MoE）**方式运行、能一次读入 **1M 级上下文**、原生处理**多模态**输入，并通过工具 / MCP / Skills 被 **Agent 化**使用。本模块的主干（Transformer、训练三阶段、Token 预测）保持不变，新增内容都标注了时间，方便你分辨"长期有效"与"2026 快照"。

**适合人群**：所有人

## 2026 年，学 M1 要额外知道什么

| 新变化 | 一句话解释 | 去哪看 |
|--------|-----------|--------|
| **推理模型 / Thinking** | 先花 token "想"，再给答案；思考深度可用 effort 调 | [M1-03](./03-training.md)、[M1-04](./04-key-concepts.md) |
| **MoE 与稀疏激活** | 总参数很大，但每次推理只激活一小部分专家 | [M1-02](./02-transformer.md) |
| **1M 级长上下文** | 2026 年旗舰模型普遍原生支持百万 token 级窗口 | [M1-04](./04-key-concepts.md) |
| **上下文缓存** | 重复的前缀可缓存，显著降低长上下文成本 | [M1-04](./04-key-concepts.md) |
| **原生多模态** | 文本、图像、音频、视频进入同一个 token 序列 | [M1-02](./02-transformer.md) |
| **Agent 化使用** | LLM 通过工具、MCP、Skills、子 Agent 完成任务 | [M4-03](../04-principles/03-agent.md)、[M4-04](../04-principles/04-mcp.md) |
