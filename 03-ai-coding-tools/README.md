## 模块概述

本模块介绍 AI 编程工具在 2026-11 的整体格局：以 Agent 工作台（Cursor 3 / Copilot / Antigravity）、终端 Agent（Claude Code / Codex / Antigravity CLI）和云端 Agent 为主线，讲清功能、价格口径与选型方法，并解释底层原理。

**适合人群**：开发同学

## 阅读建议

1. 先看 [M3-01](./01-overview.md) 建立格局与选型框架。
2. 选一个主力工具深入：[Cursor](./02-cursor.md) 或 [其他工具](./03-other-tools.md)。
3. 再用 [M3-04](./04-how-it-works.md) 理解它为什么有效、什么时候会失效。
4. 配置落地看 [M5-06](../05-practical/06-cursor-setup.md)（Cursor）、[M5-07](../05-practical/07-chatgpt-setup.md)（ChatGPT）、[M5-08](../05-practical/08-claude-setup.md)（Claude）。
